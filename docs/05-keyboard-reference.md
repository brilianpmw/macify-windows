# Phase 7: macOS Shortcuts on Windows Reference Cheat Sheet

This cheat sheet documents every macOS shortcut supported by **Macify Windows** using an Apple Keyboard or standard PC keyboard.

---

## 📋 Clipboard & Editing
| macOS Shortcut | Windows Action | Description |
| :--- | :--- | :--- |
| `Cmd + C` | `Ctrl + C` | Copy selected item/text |
| `Cmd + V` | `Ctrl + V` | Paste clipboard contents |
| `Cmd + X` | `Ctrl + X` | Cut selected text |
| `Cmd + A` | `Ctrl + A` | Select all |
| `Cmd + Z` | `Ctrl + Z` | Undo |
| `Cmd + Shift + Z` | `Ctrl + Y` / `Ctrl + Shift + Z` | Redo |
| `Cmd + S` | `Ctrl + S` | Save file |
| `Cmd + F` | `Ctrl + F` | Find in page/file |

---

## 🔤 Text Navigation & Word Jumping
| macOS Shortcut | Windows Equivalent | Description |
| :--- | :--- | :--- |
| `Option + Left` | `Ctrl + Left` | Jump cursor one word left |
| `Option + Right` | `Ctrl + Right` | Jump cursor one word right |
| `Option + Backspace` | `Ctrl + Backspace` | Delete preceding word |
| `Option + Delete` | `Ctrl + Delete` | Delete next word |
| `Cmd + Left` | `Home` | Jump to start of line |
| `Cmd + Right` | `End` | Jump to end of line |
| `Cmd + Up` | `Ctrl + Home` | Jump to top of document |
| `Cmd + Down` | `Ctrl + End` | Jump to bottom of document |
| `Option + Shift + Left` | `Ctrl + Shift + Left` | Select one word left |
| `Option + Shift + Right`| `Ctrl + Shift + Right`| Select one word right |
| `Cmd + Shift + Left` | `Shift + Home` | Select from cursor to start of line |
| `Cmd + Shift + Right` | `Shift + End` | Select from cursor to end of line |

## 🗂️ Window & App Management
| macOS Shortcut | Windows Equivalent | Description |
| :--- | :--- | :--- |
| `Cmd + W` | `Ctrl + W` | Close tab or active document |
| `Cmd + Q` | `Alt + F4` | Quit active application |
| `Cmd + M` | `Win + Down` | Minimize window |
| `Cmd + Tab` | `Alt + Tab` | Switch between running applications |
| `Cmd + Space` | Launcher (`Win + Space` / `Alt + Space`) | Open Spotlight search interface |

---

## 💻 Developer & Terminal Behavior
| In Windows Terminal / CLI | Behavior |
| :--- | :--- |
| `Cmd + C` | **Copies** selected text (does not send SIGINT) |
| `Cmd + V` | **Pastes** into prompt |
| `Ctrl + C` | **Untouched** — Sends standard `SIGINT` (halts running script/process) |
| `Ctrl + D` | **Untouched** — Sends standard `EOF` / shell exit |
